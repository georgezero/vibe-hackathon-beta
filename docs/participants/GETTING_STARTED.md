# Participant getting started

Vibe Hackathon is a project-building event. Start a private draft, build the
project with your team, review the judge-facing preview, and submit before the
event deadline.

## The shortest path

1. Open **Start a project** and create a private draft. No account is required
   to begin.
2. Continue in the browser or use the optional coding-agent prompt. The agent
   can update a draft, but the team lead should review the preview and explicitly
   approve finalization.
3. Add teammates from the **Team** area. A listed teammate gets private project
   access only after accepting the invitation while signed in; listing a name is
   not the same as granting workspace access.
4. Complete the required project details, then open **Preview**. Preview shows
   what organizers and judges will use and calls out missing readiness items.
5. Choose **Submit for judging** after reviewing the project and team. The
   confirmation explains that updates remain possible while the event deadline
   is open.

Save the draft to **My Projects** to return from another device. A draft that
has not been saved to an account can still be continued with its private link;
keep that link private because it grants edit access.

## The participant areas

- **My Projects** is the authenticated home for projects you own or have joined.
- **People** is the opt-in participant directory. Open a profile or choose
  **Message** directly from a card to start or resume a private conversation.
  The recipient does not need to be online or signed in when the message is
  sent.
- **Messages** contains private conversations with people you meet across the
  hackathon.
- **Community** is the event-wide discussion space. **General** is for event
  conversation, **Team-up** is for finding collaborators, **Technical Help** is
  for implementation questions, and **Announcements** is organizer-authored.
- **Team Chat** is different from Messages and Community: it is private to a
  project workspace and requires accepted project membership.
- **Projects** is the public gallery. It does not expose private drafts.
- **Results** appears only after the authoritative event publication is
  released. Before then, the event may still be open or judging may be underway.

## If something is incomplete

Use the readiness checklist in **Preview** or the project workspace **Status**
tab. Required project details and prize eligibility are separate: a missing
badge number can affect prize eligibility without making the project form
incomplete.

For a team access problem, check the invitation and membership state rather
than relying on an email match. For a private-link problem, use the supported
account recovery flow when the project is associated with your account. Email
recovery is not available.

## Privacy and boundaries

Keep private edit links, invitation links, passwords, API keys, patient data,
and private team details out of Community and Messages. Public profiles are
opt-in. Community and global Messages are separate from private project
workspace and Team Chat authorization.
