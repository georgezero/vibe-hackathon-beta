These screenshots were captured from the disposable Kentucky Vibes H.0 clone
(`390×844` mobile and `1440×1000` desktop). Private links and credentials are
not retained in the images; invitation-link screenshots stop before the private
link disclosure.

The contact sheet is [`h0-contact-sheet.png`](h0-contact-sheet.png). The set is
intended for cross-screen review, not as production evidence of private data.
